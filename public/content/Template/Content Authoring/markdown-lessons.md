# Markdown Entries

I write project entries as ordinary markdown files. Headings, paragraphs, lists, links, code blocks, and images cover nearly everything I need at the workbench.

## Frontmatter

When I need more control, I use optional frontmatter to set the title, layout, or a reference link. Crucible uses it to decide how to present the entry.

```yaml
---
title: First power-on test
layout: document
---
```

## Images and code

My markdown images stay centered and responsive automatically. Fenced code blocks receive syntax highlighting when their language is supported.
