# Search and Navigation

I use the sidebar to move through a project. The breadcrumb bar keeps the current category and entry visible while I work.

## Search

I open the search palette from the Search button or `Cmd + K`. It searches my entries across every project and keeps a short list of recently viewed pages.

## App home

The Home icon takes me back to the full project archive. I can return to the active project’s main page from **Overview** in the sidebar.
